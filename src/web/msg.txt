refactor(web): write LOCAL_KEY's NUL sentinel as an escape

Both files carried a literal NUL byte inside the LOCAL_KEY string literal,
which makes grep classify the whole file as binary and silently skip it --
searching either component for any term returned nothing at all.

The byte is deliberate, not a stray: LOCAL_KEY shares a map with resolved
hostnames, and a NUL prefix is what keeps the synthetic key from ever
colliding with a real host (a hostname cannot contain one). So it is now
written as a \u0000 escape rather than removed -- stripping it would have
collapsed the sentinel to "local" and folded a host actually named "local"
into the local group. Verified identical: charCodeAt(0) 0, length 6, and
still not equal to "local".
