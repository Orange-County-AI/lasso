TRANSFORMATIONS APPLIED
-----------------------
Every file below was re-encoded; no unmodified original is retained in this
repository. Tool: ImageMagick 7.1.2-27 (libwebp 1.6.0).

  Full image  <id>.webp
    magick <src> -auto-orient -strip -resize '1920x1920>' \
           -define webp:method=6 -quality 82 <id>.webp
  Thumbnail   thumbs/<id>.webp
    magick <src> -auto-orient -strip -resize '320x320>' \
           -define webp:method=6 -quality 75 thumbs/<id>.webp

  - Longest edge clamped to 1920 px (full) / 320 px (thumbnail); the trailing
    '>' means shrink-only, so nothing is ever upscaled. Aspect ratio preserved.
  - Lossy WebP, quality 82 / 75, encoder method 6.
  - '-strip' removes all metadata (EXIF/ICC/XMP), so any authorship or
    copyright metadata that upstream's files still carried does NOT survive
    into these copies. The attribution below is the record of it.
  - Several upstream files were themselves AI-upscaled before we got them
    (the '_LE_upscale_*' suffixes); those suffixes are dropped from our ids.
  - 01-omarchy-sigil had a fully-opaque alpha channel upstream (min alpha = 1);
    it is dropped in the WebP, which is visually lossless.
